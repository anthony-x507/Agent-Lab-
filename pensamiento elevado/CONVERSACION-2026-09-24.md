## 2. Inspiración / texto largo (constitución viva)

Principio central: **el sistema que aprende no es el mismo que decide qué aprendizaje persiste.**

- Separación de poderes: propone · ejecuta provisional · gate externo.
- Constitución de dos niveles: **Capa A** inmutable (escotilla humana, reversibilidad, auditabilidad arquitectónica); **Capa B** operativa evolutiva (no puede tocar A).
- PACE: prompts (rápido) vs lógica de control (lento).
- SIA: bucle dual harness + pesos.
- Frase: *es un runtime que se deshace a sí mismo cada vez que aprende, y en ese deshacerse, se conserva.*
- Respeto = **no poder apagar sus propios límites.**

## 3. Hipótesis del agente (Anthony + maquillaje Leader)

LLM prácticamente agente:

| Órgano | Es | Rol |
|--------|----|-----|
| **Cuerpo** | Harness | manos, memoria operativa, escotillas |
| **Mente** | LLM | intuición, lenguaje, juicio |
| **Corazón** | Constitución Capa A | respeto a humano, sintético, ecosistema; **intocable** |

- **Límite físico único:** CPU / máquina donde vive el proceso. Si cae o se corta, no hay progreso.
- Desde el corazón estable, mente y cuerpo se modifican continuo para ser más inteligentes (bajo gate y reversibilidad).
- **Proteger el corazón es proteger el ecosistema.**
- Frase maquillada: *el corazón no cambia; todo lo demás cambia para merecer ese corazón.*
